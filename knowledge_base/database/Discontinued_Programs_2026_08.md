# Discontinued Programs

This document lists Ironhack programs that have been discontinued and are no longer offered or enrolling students.

## Data Science and AI 1-Year Program (Germany)

- **Status:** Discontinued as of August 2026
- **Details:** The 1-year part-time program formerly offered for the German market (product code DF1Y) is no longer available. It is not accepting new enrollments.
- **Guidance for admissions:** Prospects interested in data science and AI should be directed to the **Data Science & Machine Learning bootcamp**, the **Data Analytics bootcamp**, or the **AI Engineering bootcamp**, depending on their goals.
- For questions about students previously enrolled in this program, contact the Program team on Slack.
